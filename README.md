# SpeedArti — Démonstrations Chiffrage Métiers V1.1.0

Projet statique destiné à GitHub Pages.

## Structure

- `/index.html` : page de garde et choix du métier.
- `/plaquiste/` : démo Plaquiste V0.6.0 conservée sans modification.
- `/couvreur/` : nouvelle démo Couvreur intégrée au même parcours.

## Couvreur

La démo Couvreur est une évolution du module existant :
- page de garde commune avec Plaquiste ;
- Wizard 4 étapes ;
- catalogue technique importé EDILIANS / TERREAL / MONIER (129 références, avec statut de validation) ;
- longueurs distinctes : faîtage, arêtiers, noues, rives, égout, solins, gouttières, chéneaux ;
- film sous-toiture, demi-liteaux et liteaux ;
- accessoires de couverture, ventilation et fixations ;
- gouttières, descentes et planches de rive ;
- mise en sécurité : échafaudage, ligne de vie, garde-corps, filets, échelles, monte-matériaux ;
- main-d’œuvre / heures-homme / durée séparées ;
- prix de démonstration modifiables ;
- le résultat reste un chiffrage ; la transformation en devis est seulement simulée et volontaire.

## Sécurité de la démo

Aucune connexion à la production SpeedArti. Aucun accès Supabase, stock, catalogue personnel ou tarifs fournisseurs temps réel.
