# SpeedArti — Démonstrations Chiffrage Métiers

Projet statique destiné à GitHub Pages.

## Structure

- `/index.html` : accueil et choix du métier.
- `/plaquiste/` : démonstration Plaquiste actuellement disponible.
- les autres métiers sont affichés sur l'accueil et pourront être intégrés progressivement dans leur propre dossier.

## Principe

Ce dépôt est uniquement un environnement de démonstration. Il ne remplace pas le dépôt de production SpeedArti.

## GitHub Pages

Publier depuis la branche choisie, dossier `/ (root)`.
